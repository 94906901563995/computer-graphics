# Лабораторная работа №2: Камера и освещение

Курс «Компьютерная графика», МАИ, каф. 806.

**Вариант 10 — правильный додекаэдр** (объект из ЛР №1).

Выполнено базовое задание (камера, направленный источник, рассеянный свет, материал по Блинн-Фонгу,
процедурные нормали; всё настраивается в ImGui) и дополнительные задания 1–3:

1. Два набора дескрипторов: `set = 0` — сцена (uniform-буфер + storage-буферы источников),
   `set = 1` — модель (матрица трансформации и материал).
2. Массив точечных источников в storage-буфере, затухание 1/D², добавление/удаление в интерфейсе.
3. Массив прожекторов в storage-буфере, затухание 1/D², мягкие края (внутренний/внешний угол),
   добавление/удаление в интерфейсе.

Сцена: три додекаэдра с разными материалами и пол.

Управление камерой: ползунки в окне «Камера» или ПКМ + мышь (поворот), WASD/QE (движение).

Код лабораторной находится в `source/application.cpp` и `shaders/lit.*`.

## Сборка

Нужны компилятор C++20, CMake, Ninja, Vulkan SDK (заголовки, загрузчик) и `glslc` в `PATH`.
Сторонние библиотеки (GLFW, vk-bootstrap, VMA, ImGui) CMake скачивает сам.

```bash
cmake --preset debug        # MinGW / Linux (Ninja)
cmake --preset msvc-debug   # Visual Studio 2022
cmake --build build-debug --parallel
```

## Запуск

Рабочая директория должна быть корнем проекта (шейдеры загружаются по относительным путям):

```bash
./build-debug/vulkan-starter-app        # MinGW / Linux
./build-debug/Debug/vulkan-starter-app  # MSVC
```

При сборке через MSYS2 каталог `C:\msys64\ucrt64\bin` должен быть в `PATH`
(из него берётся `libwinpthread-1.dll`).
